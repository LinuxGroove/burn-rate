# Sound credits

Almost every sound and all the music in Burn Rate is synthesized by
`tools/sfx/make_sfx.py` (run it from the repository root to make them again),
and is part of the game under its own license.

The menu sounds in `ui/` are from Kenney's **Interface Sounds** (1.0), by
Kenney (www.kenney.nl), released under **CC0 1.0** (public domain), from
[kenney-assets](https://github.com/kenvandine/kenney-assets). They are
unchanged apart from their names:

| File | Kenney's file |
|---|---|
| `ui/move.ogg` | `select_001.ogg` |
| `ui/confirm.ogg` | `confirmation_001.ogg` |
| `ui/back.ogg` | `back_001.ogg` |
| `ui/toggle.ogg` | `toggle_002.ogg` |
| `ui/error.ogg` | `error_004.ogg` |
| `ui/tick.ogg` | `tick_002.ogg` |
| `ui/open.ogg` | `open_001.ogg` |
| `ui/close.ogg` | `close_001.ogg` |

Crediting Kenney isn't required, but thank you, Kenney.
