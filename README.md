# Burn Rate

One button to fly, three lanes to dodge in. A 3D jetpack runner through a downtown tower, for one player, and party races for two to eight on one screen, on the local network and online.

Part of [LinuxGroove Games](https://linuxgroove.com). The concept is idea 22 in [game-ideas](https://github.com/LinuxGroove/game-ideas/blob/main/ideas/22-burn-rate.md).
